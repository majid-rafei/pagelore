Agent

The agent opens pages at most this often, to keep the load on websites low.

The agent keeps everything it read in the conversation, so it need not read a page again and the server can cache it. When a request would be larger than this, the oldest long results (page text, lists) are shortened to one line; if that is not enough, one extra request summarizes the older part. The latest steps, the plan and the saved results are kept as they are. 0 turns it off; smaller values (for example 30000) make long tasks cheaper but shorten sooner. Models on this computer use at most 32000.
